# Cursos

Repositorio personal reservado para almacenar los cursos que he realizado y que utilizo como **portafolio de aprendizaje**.

Aquí se recopilan apuntes, ejercicios, notebooks, scripts y certificados de distintos cursos. El objetivo es mantener un registro ordenado de mi formación y, al mismo tiempo, mostrar de forma pública las tecnologías y conceptos que he estudiado.

> Este repositorio no contiene proyectos de producción, sino material de estudio y práctica personal.

## Contenido

| Curso | Descripción | Tecnologías |
| --- | --- | --- |
| [`curso_sql/`](./curso_sql) | Curso completo de SQL: consultas, escritura de datos, creación de bases de datos y tablas, joins y temas avanzados como índices, triggers, vistas y procedimientos almacenados. | SQL, MySQL, Python |
| [`Machine Learning Sklearn/`](./Machine%20Learning%20Sklearn) | Curso de Machine Learning con Scikit-learn: algoritmos de regresión y clasificación, incluyendo notebooks, scripts y conjuntos de datos. | Python, Jupyter, pandas, scikit-learn |
| [`Inicializacion_desarrollo_con_IA.pdf`](./Inicializacion_desarrollo_con_IA.pdf) | Certificado del curso de inicialización al desarrollo con IA. | IA |

## Cómo navegar

- Cada curso se encuentra en su propia carpeta y mantiene su organización interna.
- Los archivos `README.md` de cada carpeta (cuando existan) amplían la información del curso correspondiente.
- Los notebooks se pueden abrir directamente en GitHub o ejecutar en Jupyter/Google Colab.
- Los scripts de Python requieren las dependencias habituales del curso (pandas, matplotlib, scikit-learn, mysql-connector-python, entre otras).
